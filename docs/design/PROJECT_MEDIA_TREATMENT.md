# Project media treatment

The project journey uses depth only when depth explains the product. Brand marks remain exact, flat, and optically aligned.

## MonkeyClaw

- Identity: exact MonkeyClaw head, rendered as a flat surface decal.
- True 3D: open protected core, five-stage red/judge/repro/blue/purple loop, attack paths, verifier gates.
- Semantic instrumentation: the five stages carry their real action—seed, judge, reproduce, repair, regress.
- Meaning: threats move through a bounded autonomous security system. The logo identifies the system; it is not the system geometry.

## Etch

- Identity: exact nib mark, rendered as a restrained surface engraving.
- True 3D: intent volume, constraint planes, candidates, verification gates, exposed evidence-backed FIFO die.
- Semantic instrumentation: FIFO, simulation, bounded-formal, and physical-signoff gates remain visible and distinct.
- Meaning: hardware moves from ambiguous intent to typed proof. The final physical-signoff gate remains visibly open.

## FlowE

- Identity: exact white FlowE mark, rendered as a flat masked image that reveals only through the real artwork.
- 2.5D: exact logo, task cards, focus current, local-index handoff. No enclosing device shell.
- Semantic instrumentation: the task field uses real planner language and isolates one focus block as the chapter narrows.
- Meaning: obligations organize into a calm plan and then one focus stream. No extruded or approximated logo geometry.

## Argyph

- Identity: exact A/G mark, rendered flat on the indexed surface.
- 2.5D: open repository, semantic-chunk, and symbol-graph field; sonar and query signals. No enclosing appliance.
- Semantic instrumentation: repository, semantic, and symbol tiers label the graph without becoming UI chrome.
- Meaning: local code intelligence resolves across indexed layers. The data stack has depth; the identity does not.

## Shared rules

- Never reconstruct a logo from generic primitives when approved artwork exists.
- Do not put a second plaque behind a mark unless the real product has one.
- Do not turn unrelated projects into a family of rounded black devices.
- Use real 3D for physical systems, spatial flows, and state transitions.
- Use 2.5D for interface fragments, indexed layers, labels, and planar information.
- A logo may reveal, mask, light, or move in perspective. Its silhouette and proportions must stay exact.
- Motion must be scroll-derived, reversible, restrained under reduced motion, and subordinate to legibility.
