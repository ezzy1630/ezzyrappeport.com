Next.js 15, React 19, TypeScript, Three.js. Source for [ezzyrappeport.com](https://ezzyrappeport.com).

## Develop

```sh
npm ci
npm run dev
```

`npm run dev` runs Next normally and also accepts the supervised preview's `--host`, `--port`, and `--strictPort` flags through a small adapter. Existing production hosting remains unchanged.

## Current experience

The homepage combines the reference composition with live, individually draggable glass lettering. Its sunlit silver-blue water plate was generated by removing the typography and UI from the supplied reference; the photographic detail is refracted by a live heightfield. Thirteen GLB letters retain mass-dependent return springs, contact impulses, wave response, and keyboard movement. The existing gallery, biography, résumé, and case studies remain server-rendered.

`src/components/playground/Portfolio.tsx` owns the page and uses `src/components/water-study/WaterHero.tsx`. The latter loads `scene.ts`, `optics.ts`, and `environment.ts` only for the hero. The water solver is `src/components/playground/water-field.ts`; `surface.ts`, `field-texture.ts`, and `dynamics.ts` connect it to the optical and letter response. The retained `glass-scene.ts`, kinetic-canvas, and ocean-experience implementations are historical renderers, not the homepage path.

The renderer uses full-resolution HDR refraction, a shallow glass-depth layer, half-float wave heights and gradients, cached shadows, and a small caustic pass. It targets 60 presentations per second during interaction and 30 at idle, stops offscreen and in hidden tabs, and reduces the secondary caustic target under sustained load. The main drawing buffer is capped at 3.2 million pixels and DPR 2. These are budgets, not guarantees on every device.

Scene settings provide pause, reset, ripple, and touch-play controls. Normal vertical touch scrolling remains the default. Focus the scene and use arrow keys to move a letter, with `[` and `]` selecting another letter. Reduced motion renders a resting frame; Save-Data, initialization failure, and context loss retain the matching poster. Project pages do not load the renderer.

## Blender asset workflow

Blender 4.5 LTS runs through its background CLI; no MCP server is needed. The current glyphs reconstruct the existing silhouettes with continuous rounded caps and counter walls, preserving all 13 rest transforms and exact bounds. Eight meshes share 62,400 visible triangles. Export validation checks closed surfaces, positive signed volume, outward normals, byte size and layout.

Install the geometry preparation dependencies in a Python environment:

```sh
python3 -m pip install numpy scipy pillow scikit-image
python3 scripts/blender/cast_glass/rebuild.py --blender /path/to/blender --source assets/blender/playground/optical-source.blend --output /tmp/portfolio-cast-glass --water public/assets/water/shallow-desktop-v1.webp --baseline assets/blender/playground/optical-source.json
```

The pipeline extracts the source silhouettes, reconstructs and simplifies the curved surfaces, fixes outward normals, exports and validates the GLB, and renders one final 1600×780 poster at 192 Cycles samples. Intermediate geometry stays in the chosen output directory. The source scene is preserved; the selected final scene is `assets/blender/playground/polished-glyphs.blend`.

Copy output `playground-glyphs.glb` and `playground-glyphs.json` into `public/assets/hero/`. Preserve the Blender scenes and `silver-studio.hdr` as editable source assets. The browser now builds its studio reflections procedurally; it does not download that HDR.

### Matching browser posters

Open `/?capture=1` in a WebGL browser. At a 1440×810 desktop viewport, open **Scene settings**, pause, reset, and capture the scene. Repeat at 390×844 for the mobile layout. Download both PNGs, then run:

```sh
node scripts/encode-water-hero-posters.mjs /absolute/path/to/desktop.png /absolute/path/to/mobile.png
node --experimental-strip-types scripts/water-study-tests.mjs
```

The encoder preserves the captured resolution, writes desktop/mobile WebPs, and records source hashes in `public/assets/hero/water-hero-poster.json`. The optical tests reject stale posters after shader, scene, geometry, or water-plate changes. `?capture=1` also exposes timing data in the canvas `data-hero-diagnostics` attribute. Ordinary visits do not collect those samples.

The source water asset is `public/assets/hero/reference-water-v1.webp`. Its generation prompt and provenance are recorded in the reference-match review. Keep the generated plate separate from actual product screenshots.
